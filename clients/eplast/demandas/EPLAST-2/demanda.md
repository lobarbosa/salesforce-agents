# Estabelecer baseline dos indicadores comerciais do projeto

Antes de iniciar as ondas de produtividade, gestão e marketing, é preciso registrar o valor atual dos indicadores que o projeto promete melhorar (ex.: tempo médio de resposta a lead, oportunidades paradas, taxa de conversão), para que o impacto das ondas seguintes possa ser medido de forma objetiva.

**Critérios de aceite propostos**
- Existe uma lista de indicadores comerciais com o valor atual de cada um, datado.
- O cliente confirmou por escrito que esses são os indicadores usados para medir o sucesso do projeto.
